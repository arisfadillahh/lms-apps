# Error Fixing Log

This directory is the technical memory for LMS bug fixes. It is maintained by the coding agent and developers, not by Coach or Coder.

Before fixing a bug, search this directory first. After the fix is verified, append an entry to the current monthly file and update `index.md`. Entries are append-only so previous decisions and regression risks stay visible in Git history.

User reports remain in the `issue_reports` database table. A database report can be linked here through its `BUG-XXXXXXXX` reference without copying personal or sensitive data.
